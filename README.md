# php-web-shop-oss

A simple educational product store built with **pure PHP & MySQL**. This project was originally developed as part of a national skills competition (Olympiad) but is now open-sourced as a learning resource for beginners and contributors.

[![PHP Version](https://img.shields.io/badge/PHP-8.x-777BB4?style=flat&logo=php&logoColor=white)](https://php.net)
[![MySQL](https://img.shields.io/badge/MySQL-8.0-4479A1?style=flat&logo=mysql&logoColor=white)](https://mysql.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## Features

- Product listing with search & sort
- Shopping cart using `localStorage`
- Order placement with stock reduction
- Admin panel (Add / Edit / Delete products)
- Responsive design

---

## Tech Stack

- **Backend:** PHP 8.x (no frameworks)
- **Database:** MySQL (MySQLi)
- **Frontend:** HTML5, CSS3, JavaScript

---

## Quick Start

```bash
git clone https://github.com/MobinaSafarirad/php-web-shop-oss.git
Import sql/shop_db.sql to your MySQL database.

Update database credentials in includes/db_connect.php.

Run locally (XAMPP / LAMP / MAMP).

🔐 Admin Access
URL: admin/login.php

Default: admin / 1234
